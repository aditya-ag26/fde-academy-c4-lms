# `activities/submissions/` — pointer only

**No student files are ever committed here.** This directory contains this README and
nothing else.

## Where submissions actually live

**Discussions.** Students have read access to this repository and never push, branch,
or open a pull request against it.

To submit: open a thread in the **Assignments** category using the submission form.

## Why it works this way

Two reasons, and the second is the real one:

1. **Access.** Read-only students cannot commit files. Discussions needs only read.
2. **Pedagogy.** A thread captures the approach, the wrong turn, the correction and the
   review conversation. A file drop captures the final artefact and nothing else. The
   discussion is where the learning is visible.

This directory exists so that anyone looking for submissions finds this explanation
rather than concluding the feature is missing.
