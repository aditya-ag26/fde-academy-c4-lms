# `activities/briefs/`

One file per activity. `A<NN>-<slug>.md`, ids stable forever.

A brief states, in this order:

1. **What you will build** — the deliverable, concretely
2. **Why** — what capability this is practising
3. **Constraints** — what is and is not allowed
4. **How you are assessed** — a link to the rubric, which is published by default
5. **How to submit** — the Discussion category, with a link to the form

Deadlines, review mode and the rubric link live in frontmatter, not prose, so the
catalogue and deadline reminders can read them. See
[frontmatter.md](../../docs/01-authoring/frontmatter.md).

`discussion_url:` is written by the publish action. Do not type one in.
