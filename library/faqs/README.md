# `library/faqs/`

Largely **generated** from Discussion threads that were answered.

## Why this is the highest-value automation in the system

An FAQ harvested from Discussions is grounded in questions students **actually asked**.
It cannot invent a problem nobody had, which is the failure mode of hand-written FAQs —
they answer the questions the author imagined, not the ones people have.

## The verification gate

A **marked** answer means it satisfied the person who asked. That is not the same as
being correct.

Every harvested FAQ carries `verified_by:` — a staff handle — before it is published.
Anything in `library/` carries the repo's authority, and an answer that worked for the
wrong reason should not inherit that.

See [bot-policy.md](../../docs/02-delivery/bot-policy.md).
