# `library/case-studies/`

Worked real-world scenarios: what the situation was, what was tried, what actually
happened, and why.

## Naming: `CS-<NN>-<slug>.md`

Ids are stable forever. `CS-01` stays `CS-01`.

## What makes a case study worth writing

The wrong turn. A case study that presents a clean path from problem to solution
teaches less than one that shows the plausible approach that failed and why it was
plausible. If there was no surprise in it, it is an explainer — put it in
[`../concepts/`](../concepts/).
