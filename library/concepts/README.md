# `library/concepts/`

Glossary entries, cheatsheets, and explainers that more than one session points at.

## The test

If two sessions would both want to link to it, it belongs here rather than inside
either session folder. Duplicating an explainer into two session folders means fixing
an error twice, and forgetting the second one.

Keep entries short and linkable. A concept page that needs a table of contents is
probably three concept pages.
