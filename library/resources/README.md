# `library/resources/`

Reading lists, papers, external links, tools.

## Annotate, or do not include

A bare link is not a resource. Each entry says **why it is here and who it is for** —
"the clearest explanation of X, skip the first two sections", not just a URL. An
unannotated link list is a bookmark dump, and nobody reads it twice.

External links rot. The link checker in CI will flag dead ones; when it does, either
replace or remove them rather than leaving a known-dead link in place.
