# `library/coding-questions/`

Practice problems. Markdown, because they need code blocks, but carrying structured
frontmatter so they can be indexed and filtered.

## Naming: `CQ-<NNN>-<slug>.md`

## Solutions are not here

`has_solution: true` in the frontmatter means a solution exists **in the private
repo**. It is published here by an action after the deadline.

There is no `solutions/` folder in this repository, and there must never be one.
Students have read access to every file in this repo, linked or not — an unlinked
folder is not a hidden folder. See
[access-control.md](../../docs/04-operations/access-control.md).

## The dual-home rule applies

A coding question is a **file here (canonical)** and a **published Discussion thread
(working copy)**. Corrections are a PR to the file; the action re-syncs the thread.
Never edit the question text in the thread.

## `by-difficulty/`

Generated views. Do not hand-edit.
