# Authoring templates · PLATFORM REPO

Templates **staff** use to author content: session README, pre-read, post-read,
notes, activity brief, rubric, case study, notice.

Each carries correct frontmatter and section headings with guidance comments, so a new
author starts from something valid rather than from a blank file.

Not to be confused with `library/templates/` in the content repo, which holds templates
**students** use.
