## Where things happen

<table>
<tr>
<td width="50%" valign="top">

### 📁 In this repository

Everything you **read**.

- [`batch/`](batch/) — sessions, notices, the calendar
- [`library/`](library/) — concepts, case studies, question banks
- [`activities/`](activities/) — briefs and the rubrics that mark them
- [`docs/`](docs/) — how the platform runs

</td>
<td width="50%" valign="top">

### 💬 In [Discussions](../../discussions)

Everything you **do**.

- Ask about a session → **Doubts**
- Ask anything else → **Q&A**
- Hand in an assignment → **Assignments**
- Can't log in, tool won't install → **Help Desk**

A broken document is an [issue](../../issues/new/choose), not a discussion.

</td>
</tr>
</table>

> [!NOTE]
> **You have read access, and that is all you need.** You will never push a file or open
> a pull request here. A thread captures your approach, the wrong turn and the
> correction; a file upload captures only the result — and the reasoning is the part
> worth reading later. [Why, in full →](docs/04-operations/access-control.md)
