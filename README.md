## 🧭 Where do I go?

|  | I want to… | Go to |
|:--:|:--|:--|
| 🙋 | **Ask about a session** | Discussions → **Doubts** |
| ❓ | **Ask anything else** | Discussions → **Q&A** |
| 📤 | **Submit an assignment** | Discussions → **Assignments** |
| 🛠️ | **Report a login / tooling problem** | Discussions → **Help Desk** |
| 🐛 | **Report a wrong or broken document** | [Open an issue](../../issues/new/choose) |
| 📅 | **See the schedule** | [`batch/calendar.md`](batch/calendar.md) |
| 📚 | **Find reference material** | [`library/`](library/) |
| 📋 | **See every activity** | [`activities/catalogue.md`](activities/catalogue.md) |

> **You have read access, and that is all you need.** You never push files or open a pull
> request here — everything happens in Discussions. A thread captures your approach, the
> wrong turn and the correction; a file upload captures only the result.
> [Why →](docs/04-operations/access-control.md)
