## Two things worth knowing

<table>
<tr>
<td width="50%" valign="top">

**🔑 You have read access, and that is enough**

You will not push, branch, or open a pull request here. Everything you do — asking,
answering, submitting, being reviewed — happens in **Discussions**.

This is deliberate. A thread captures your approach, the wrong turn and the
correction; a file upload captures only the final artefact.

[Why, in full →](docs/04-operations/access-control.md)

</td>
<td width="50%" valign="top">

**📄 Briefs live in two places**

The file in [`activities/briefs/`](activities/briefs/) is **canonical**. The
Discussion thread is a published copy of it.

If the two ever disagree, **the file is right** — and that is a bug worth
[reporting](../../issues/new/choose).

Never assume the thread is the newer version.

</td>
</tr>
</table>
