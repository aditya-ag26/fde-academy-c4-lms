# Activity solutions · PRIVATE REPO

Solutions to `activities/briefs/`, held until their deadline passes.

## Released by an action

1. Written here, alongside the brief they answer.
2. After the deadline, a scheduled action opens a PR into the content repo.
3. A human merges. The merge is the publication.

## Why not an unlinked folder in the content repo

Students have read access to **every file** in that repository. Unlinked is not hidden.
A folder called `solutions/` in a repo a student can read is a solutions folder a
student can read.

See [access-control.md](../../docs/04-operations/access-control.md).
