# `people/` · PRIVATE REPO

Roster, staff assignments, review routing.

## Handles only

GitHub handles. **No real names, no email addresses, no phone numbers.** Even in the
private repository — a git history is forever and a repo's access list changes.

Where a display name is genuinely needed, it lives in `.config/batch.yaml` in the
content repo, for staff only, and only because it appears in student-facing pages.

## Why this is not in the content repo

Students have read access to every file in the content repo. Roster data about other
people is not student-facing, regardless of how little it contains.
