# Coding question solutions · PRIVATE REPO

Solutions to `library/coding-questions/`, released after the relevant deadline by the
same action that releases activity solutions.

A coding question in the content repo carries `has_solution: true` in its frontmatter.
That flag means *a solution exists here* — not that one is present in the content repo.
