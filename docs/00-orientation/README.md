# `docs/00-orientation/`

For a student on day one. Assume they have never used GitHub Discussions and are not
sure whether this repository is a website, an app, or homework.

Everything here is written to be read **once, quickly, before the first session**.
Anything that needs to be read twice belongs somewhere else.

| Document | For |
|---|---|
| [`your-first-week.md`](your-first-week.md) | What happens, in order, and what to do |
| [`glossary.md`](glossary.md) | Every term used in the batch |

Keep it short. An orientation doc nobody finishes is the same as no orientation doc.
