# `docs/` — how this LMS is run

Documentation **about** the LMS, for the people running it and the people learning in
it. Not course content — that is [`batch/`](../batch/) and [`library/`](../library/).

| Folder | Audience | Holds |
|---|---|---|
| `00-orientation/` | students, day one | what this repo is, how to find things |
| `01-authoring/` | staff writing content | frontmatter schema, style, templates |
| `02-delivery/` | students + staff | Discussions guides, bot policy |
| `03-automation/` | staff | Drive workflow, the pipeline, what runs when |
| `04-operations/` | staff | access control, provisioning, runbooks |
| `05-contributing/` | staff | how to propose a change |
| `09-design-notes/` | whoever builds this next | why it is shaped this way |

## Start here

- New student → [`00-orientation/`](00-orientation/) and `START-HERE.md` at the repo root
- Adding anyone to anything → [`04-operations/access-control.md`](04-operations/access-control.md)
- Writing content → [`01-authoring/frontmatter.md`](01-authoring/frontmatter.md)
