# `docs/02-delivery/`

How the batch is actually run day to day — and, because Discussions is the primary
interaction surface, this is where the student-facing guides live.

Two audiences, two documents. A combined guide serves neither:

| Document | Audience | Answers |
|---|---|---|
| [`discussions-for-students.md`](discussions-for-students.md) | students | where do I post this, and how do I get an answer |
| [`discussions-for-faculty.md`](discussions-for-faculty.md) | staff | how do I triage, when do I escalate, what does the bot do |
| [`bot-policy.md`](bot-policy.md) | both | what the bot will and will not do, especially about answering |
| [`submission-loop.md`](submission-loop.md) | both | brief → thread → submit → review → revise, as a diagram |
| [`review-guide.md`](review-guide.md) | both | How to give useful review. A peer-review culture is set by whether anyone explained this |
