# `docs/03-automation/`

How content gets from a recording or a Drive folder into this repository without anyone
touching git.

Most faculty will never have repo access. **Drive is their interface**, not merely an
ingestion inbox — so these documents are written for someone who will never open a
terminal.

| Document | For | Covers |
|---|---|---|
| [`drive-guide.md`](drive-guide.md) | **Faculty** | The four folders, what to upload, how to review a draft |
| [`pipeline-overview.md`](pipeline-overview.md) | Staff | The five stages, the provenance contract, the skills, what is undecided |

> **Not live yet.** The pipeline is designed and scaffolded; no implementation code
> exists. Until it does, send material to the batch owner directly.

The pipeline itself is staff-only and lives in the private repo — staged here at
[`_staging-private-repo/automation/`](../../_staging-private-repo/automation/).
