# `docs/03-automation/`

For staff. How content gets from a recording or a Drive folder into this repository
without anyone touching git.

Most faculty will never have repo access. **Drive is their interface**, not merely an
ingestion inbox — so these documents are written for someone who will never open a
terminal.

The pipeline code itself is staff-only and lives in the private repo (staged at
`_staging-private-repo/automation/`).
